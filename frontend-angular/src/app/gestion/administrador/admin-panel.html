El administrador puede crear cuentas de muestra y asignar roles internos. Las cuentas ordinarias pueden solicitar publicaciones sin un rol especial.

3. Roles internos

Solicitar la publicación de un proyecto es opcional para cualquier cuenta; no es un rol.

Administrador

Gestiona cuentas y asigna roles internos.

Supervisor

Revisa entregas, decide y controla publicaciones.

Lector

Consulta el catálogo y puede solicitar la publicación de un proyecto si lo desea.
